# Dutch Language Pack for MikoPBX

[![MikoPBX](https://img.shields.io/badge/MikoPBX-2025.1.1+-blue.svg)](https://github.com/mikopbx/Core)
[![License](https://img.shields.io/badge/License-GPLv3-green.svg)](LICENSE)

Complete Dutch language support for MikoPBX including 638 professional voice prompts and full UI translation.

## Installation

1. Open **System -> Extension Modules -> Marketplace**
2. Search for "Dutch Language Pack"
3. Click **Install** and **Enable**
4. Go to **General Settings** and select **Nederlands (nl-nl)**

## What's Included

- 638 Dutch voice files (greetings, menus, digits, letters)
- 16 translation files for complete UI localization
- Automatic integration with MikoPBX

## TTS Attribution

Voice prompts were generated using neural TTS (Text-to-Speech) technology:

- **Engine**: [Piper TTS](https://github.com/rhasspy/piper)
- **Voice model**: `nl_NL-mls-medium` (rhasspy/piper-voices)
- **Sample rate**: 22050 Hz
- **Format**: WAV (PCM signed 16-bit, mono)

The text for each prompt is stored in `Sounds/core-sounds-nl-nl.txt` for reference and regeneration.

On module installation, MikoPBX automatically converts WAV files to all Asterisk formats (ulaw, alaw, gsm, g722, sln) for optimal codec compatibility.

Tone and silence files (`beep`, `beeperr`, `ascending-2tone`, `descending-2tone`, `confbridge-join`, `confbridge-leave`, `silence/*`, `sng_mcu*`, `tt-monkeys`) are kept from official Asterisk core sounds (CC BY-SA 4.0) and are not regenerated by TTS.
